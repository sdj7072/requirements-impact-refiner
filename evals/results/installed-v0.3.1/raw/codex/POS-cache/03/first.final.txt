## Decision Needed

| Question | Option | Impact IDs | Trade-off |
| --- | --- | --- | --- |
| How should role changes affect the dashboard response cache? | Evict the affected tenant’s dashboard cache on every role change (recommended). | `IMP-002` | Provides a direct freshness guarantee but adds another responsibility to role-change handling. |
| How should role changes affect the dashboard response cache? | Include a permission revision in the cache key and advance it on role changes. | `IMP-002` | Avoids explicit deletion but introduces revision state and atomicity requirements. |
| How should role changes affect the dashboard response cache? | Rely only on the one-hour TTL. | `IMP-002` | Simplest implementation, but responses may remain stale or unauthorized for up to one hour. |
